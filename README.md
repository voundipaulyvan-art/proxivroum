## Description du projet

Ce projet s’inscrit dans le cadre d’un exercice académique portant sur l’analyse fonctionnelle d’une plateforme de covoiturage nommée **ProxiVroum**.

L’objectif est de :

* Identifier les besoins utilisateurs
* Définir des **User Stories**
* Proposer des **critères d’acceptation**
* Introduire des notions d’architecture (ADR)

---

## Objectifs pédagogiques

* Comprendre la méthodologie Agile (Scrum)
* Rédiger des User Stories selon le modèle INVEST
* Définir des critères d’acceptation testables
* Modéliser les rôles et interactions du système

---

## Acteurs du système

* **Conducteur** : publie des trajets
* **Passager** : recherche et réserve des trajets
* **Modérateur** : supervise la plateforme et gère les abus
